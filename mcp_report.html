ГдеЧто
test_search.py (кейс 299) На стейдже нет фичи «Популярные запросы». Когда выкатят — тест автоматически перестанет скипаться
test_product_page.py (кейс 68) Hover на .compare__product не меняет визуальный стиль. Если такое поведение — баг UI, отметить и тикетом; иначе оставить как SKIP
Конфликт ID на главной В DOM главной странице есть два элемента с id search__input (десктоп + мобильная разметка ≤1024). Это формальный баг разметки — лучше дать разные id, тесты тогда станут проще
